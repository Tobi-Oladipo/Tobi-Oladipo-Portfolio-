Predictive modeling

Healthcare Analytics Capstone (CLABSI Prediction)

  • Analyzed healthcare data to identify risk factors associated with hospital-acquired bloodstream infections.
  • Used Python and statistical modeling techniques to improve predictive performance and support evidence-based recommendations.
Data
Texas Children's Hospital, in a graduate capstone practicum with a six-person team and faculty mentors.
Question
Will a patient develop a central line-associated bloodstream infection (CLABSI) within the next three days? True or False.
Data problems
A heavily imbalanced target, 239,605 missing values and outliers.

Four model types

  • Weighted neural network
  • Bagged decision trees
  • Support vector machine
  • XGBoost

Evaluation

Stratified k-fold cross-validation · precision, recall, F1, ROC-AUC · decision and cost curves, since a missed infection costs more than a false alarm.

Python · scikit-learn · XGBoost
